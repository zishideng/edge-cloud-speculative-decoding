\section{Implementation}
\label{sec:impl}
\cape{} is implemented in the Python edge client of our testbed (Section~\ref{sec:testbed}). A lookahead client of 163 lines manages background draft calls to llama.cpp on a worker thread. It checks prefix compatibility and records every speculative token as reused, discarded or unused. \cape{} adds the pipeline model (49 lines) and the controller (121 lines) on top of it. Draft and target exchange token IDs, so no text is re-tokenized between rounds, and the draft server is not asked for token probabilities. The cloud verification service is a FastAPI front end to vLLM that returns the target's top-1 token at every draft position; it is identical for all methods. Every request logs per-round timings, all speculative events, every controller decision and the power trace, which allows each number in this paper to be recomputed from raw records.
