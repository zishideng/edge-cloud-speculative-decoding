\section{Reproducibility}
\label{app:repro}
All numbers, tables and figures in this paper are generated from retained raw records by \path{scripts/extract_evidence.py} and \path{scripts/make_assets.py}; the text reads every value from the generated \path{numbers.tex}. Only the 2\,ms and 100\,ms conditions are used. The raw records, power traces, frozen plans and source snapshots are in the repository:
\begin{itemize}
\item Main evaluation: \path{results/compare_20261010/full_110} (plan \path{full_110_plan.json}; host activity during the run is logged in \path{full_110_maintenance.log});
\item Held-out Set~1: \path{results/pipeline_research_20261009/confirm_markov};
\item Held-out Set~2: \path{results/pipeline_research_20261009/final_markov_v2}.
\end{itemize}
Models and software: draft \path{bartowski/Llama-3.2-1B-Instruct-GGUF} (Q4\_K\_M) on llama.cpp build b9744 with JetPack 6.2.1; target \path{hugging-quants/Meta-Llama-3.1-8B-Instruct-AWQ-INT4} on vLLM 0.26.0 and PyTorch 2.11.0 (conda environment) with an RTX 3080 (10\,GB), NVIDIA driver 580.173.02, Ubuntu 24.04.4 LTS (kernel 7.0.0-28).
