**Title:** CAPE: Critical-Path-Aware Prefetching for Fast and Energy-Aware Edge–Cloud Speculative Decoding

Draft first written on 2026-10-10 and revised on 2026-10-12 to use the full 110-prompt evaluation (1,540 requests) as the main result. Author: Zishi Deng, University of Auckland. The venue is not yet chosen; for a double-blind venue, anonymize the author block and the campus-network details.

## Compile

- **Overleaf:** upload the zip, set `main.tex` as the main file. pdfLaTeX and XeLaTeX both work (the preamble selects Times fonts for either engine).
- **Locally:** `bash scripts/build.sh` (uses `latexmk` or Tectonic).

## Regenerate the numbers, tables and figures

`extract_evidence.py` and `make_assets.py` still read the removed 2026-10-10 data and need porting to the four-pair runs. Run from the repository root:

```bash
python3 paper/cape_20261010/scripts/extract_evidence.py   # raw records -> data/evidence.json
python3 paper/cape_20261010/scripts/make_assets.py        # evidence -> numbers.tex, tables/, figures/
```

Undefined numbers compile as **??** and are reported in the LaTeX log as `Undefined CAPE number`.

## Evidence used

Four pairs × 110 prompts × low (2 ms) / high (100 ms) / dynamic delay; ten methods (13,200 requests). Current numbers are in `numbers_draft.tex`, generated by `scripts/provisional/` from the `analysis/SUMMARY.md` files below.

| Role | Directory |
|---|---|
| CAPE and fixed windows (Llama, Qwen, Gemma-2) | `results/final_20261020/{llama,qwen,gemma}_full_dist_110` |
| Pipelined baselines (Llama, Qwen, Gemma-2) | `results/baselines_20261022/{llama,qwen,gemma}_new_110` |
| All methods (Gemma-3) | `results/gemma3_20261026/gemma3_full_110` |
| Delay sweep and ablation (Gemma-3, 30 prompts) | `results/gemma3_20261026/gemma3_delay_sweep`, `gemma3_ablation` |

Method names: `fixed_fast` = Fixed-4, `fixed_g2`/`fixed_g8` = Fixed-2/Fixed-8, `sync_g4` = Sync-4, `markov_w0_dist` = CAPE-S, `markov_w05_dist` = CAPE-E, `pearl`, `picospec`, `pipesd`, `hf_default` = HF assisted.
