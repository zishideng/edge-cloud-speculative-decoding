# Project cleanup — October 8, 2026

The maintained experiment path is `run_downloaded_benchmarks.sh` ->
`experiments.adaptive_research` -> the fixed and latency-regime clients.
The only selectable live methods are `fixed`, `fixed_fast`, and `regime`.
The downloaded datasets, strict K=1 verification, energy sampling and current
model-service launch scripts remain supported.

Removed components include the earlier prefetch, warmup, entropy-window and SLO
experiments; buffered, streaming-cancellation and first joint-controller
prototypes; the superseded suite runners and analysis tools; their obsolete
tests and runbooks; unreferenced earlier suite/validation/startup outputs; and
the earlier manuscript package. No model weights or downloaded task data were
selected for deletion.

The live runner no longer imports the retired suite merely to enrich request
metrics. That calculation is now in `common/result_metrics.py`. Shared fixed
lookahead, greedy drafting, verification and latency-regime algorithms are
unchanged. Reports show N/A for tasks without an implemented accuracy scorer.

The ongoing downloaded-data experiment, the completed paper reproduction, and
the October 7 research campaign remain. The research campaign contains the
paper's raw confirmation measurements, negative evidence and frozen source
snapshots. Those are retained research evidence, even where a prototype is no
longer a supported live implementation. Historical labels in archived records
remain intact. Historical report regeneration validates the archived source
snapshots rather than requiring today's source tree to match old hashes.

`CLEANUP_20261008.json` records deleted paths, byte/file counts, validation and
the source/old-manuscript recovery archive outside this project. Obsolete result
directories are deleted; they are not included in that source recovery archive.
The older experiment source still exists in retained research snapshots where
required for the paper's provenance.

Cleanup was requested while a downloaded GSM8K experiment was running. The
service and experiment were not stopped. Maintenance timing is recorded in
`results/downloaded_benchmarks/maintenance_cleanup_20261008.json`; local board
energy includes concurrent host activity, so this run is not an isolated
hardware measurement. No timed request was rerun or silently excluded by the
cleanup.
